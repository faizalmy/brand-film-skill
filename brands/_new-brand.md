# <Brand> profile

Copy to `brands/<brand>.md` and fill every line before building. Unknown means ask the user or measure, never guess.

- **Site:** URL the film zooms into; the pages and the interaction to capture (a theme toggle, a menu, a real click).
- **Text sources:** where the verbatim lines come from (homepage subline, docs, llms.txt); the exact line for the
  opening and the end card; the domain shown.
- **Logo:** SVG source; the lead element (dot, corner, stroke end); ring/container shape; wordmark letters.
- **Palette:** ink, paper, light ink, dim (the brand's own neutrals); any colour the brand truly owns.
- **Type:** the site's typeface and tracking; licensed file to self-host.
- **Product:** 3-4 real views to capture (URLs), what to drag in each, which measurements to show.
- **Music:** where the bed comes from (and whether generation is allowed); BPM after `beat.py`.
- **SFX:** allowed hits; anything banned.
- **Output:** project folder, composition name, mp4 name, links for viewers.
- **Capture setup:** where Playwright resolves from; login or license needed.
- **Liked / rejected:** fill as the user reviews (frames and what).
